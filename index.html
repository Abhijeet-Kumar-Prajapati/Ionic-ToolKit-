⚙️ Realistic Features

  • Modules run standalone — each module has its own HTML file in the modules/ folder, can open directly in a browser.
  • Works like a single app — one dashboard with all tabs on one page.
  • Offline support — service worker (sw.js) caches files.
  • PWA / Install — "Install app" adds an app icon to the home screen.
  • No backend / DB — everything runs in the browser, saved in localStorage.
